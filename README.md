# F1 Race Strategy Simulator

A real-time Formula 1 pit stop strategy simulator built with historical F1 race data.

## Live Demo
https://f1-strategy-simulator-26.streamlit.app/

## What it does
- Input live race conditions: lap number, position, tyre compound, tyre age, weather, gaps to cars ahead and behind
- Get instant pit stop recommendations based on real F1 strategy logic
- Visualise tyre degradation curves across all three compounds
- Explore historical season points data

## Built with
- Python
- Streamlit
- Plotly
- Pandas
- Kaggle F1 World Championship Dataset
